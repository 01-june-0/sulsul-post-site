# 술술포스팅 공개 페이지 (Sulsul Post public site)

GitHub Pages: https://01-june-0.github.io/sulsul-post-site/

- `privacy/`: 개인정보 처리방침 / Privacy policy
- `selectors/v1/`: 확장이 받아 쓰는 사이트 구조 설정 파일. 서명된 데이터(JSON)이고 코드는 없습니다. / Signed site-structure data the extension reads. No code.
- `licenses/v1/revoked.json`: 회수한 라이선스 키 번호 목록(서명됨, 이름 없음). / Signed list of revoked license key numbers (no names).

이 저장소는 비공개 개발 저장소에서 `npm run site:deploy`로 만듭니다. 여기서 직접 고치지 않습니다. / Generated by `npm run site:deploy` from the private development repository; not edited by hand.
