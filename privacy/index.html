술술포스팅 개인정보 처리방침 / Sulsul Post Privacy Policy

최종 업데이트 / Last updated: 2026-10-06

한국어

술술포스팅은 사용자 데이터를 받는 개발자 서버가 없고, 사용자의 데이터를 수집·판매·공유하지 않습니다. 분석 도구, 광고, 추적기를 쓰지 않습니다.

기기에만 저장하는 것

아래 데이터는 이 브라우저 프로필 안(chrome.storage, IndexedDB)에만 저장됩니다.

  • 설정, 작성 정보(주제·키워드·메모 등), 동의 기록
  • 초안과 버전 기록(최근 30개), 생성하거나 첨부한 이미지와 사진
  • 연결한 글쓰기 화면의 탭 정보(주소, 제목)
  • '상위 글 참고'로 읽은 글
    • 본문 발췌는 24시간 뒤 자동으로 지웁니다.
    • 참고한 글의 제목·주소와 요약 통계(글자 수, 자주 나온 소제목 낱말·태그)는 그 초안의 기록에 남습니다.
  • 실행 기록(최근 500건): 긴 글, 주소의 검색어, 이메일, 전화번호는 가려서 남깁니다.
  • 받아 온 사이트 구조 설정 파일과 마지막 확인 시각(아래 '사이트 구조 설정 확인')

사용자가 실행할 때만 밖으로 나가는 것

술술포스팅은 사용자가 버튼을 누를 때만, 사용자가 고른 사이트에서, 일반 브라우저 창으로 동작합니다.

  • AI 서비스(Gemini, ChatGPT, Claude)
    • 사용자가 이미 로그인해 둔 AI 사이트를 팝업 창으로 열고, 프롬프트를 대신 입력합니다.
    • 프롬프트에는 작성 정보, 참고 글 발췌, 초안이 들어가고, 사용자가 고르면 첨부한 사진과 참고 이미지도 들어갑니다.
    • 이 내용은 해당 AI 서비스의 개인정보 처리방침에 따라 처리됩니다. ChatGPT는 임시 채팅, Claude는 시크릿 채팅으로 보내도록 설정할 수 있습니다.
  • 네이버 검색·블로그: '상위 글 참고'를 쓰면 검색 결과와 블로그 글을 브라우저 창에서 읽습니다.
  • 글쓰기 화면(네이버 블로그·카페, 티스토리)
    • 사용자가 연결한 화면에 제목, 본문, 이미지, 태그를 입력합니다.
    • 이미지는 그 사이트의 편집기가 자기 서버에 올립니다. 발행은 항상 사용자가 직접 합니다.
  • 인스타그램·Threads: [인스타그램에 넣기]·[Threads에 넣기]를 누르면, 열어 둔 탭의 작성창에 사진과 캡션, 연속 글을 넣습니다. 공유·게시는 사용자가 직접 합니다.
  • AI 이미지 주소: 사용자가 만든 이미지를 받아 오려고 해당 AI 서비스의 이미지 주소에 접속합니다.
  • 이미지 찾기 (구글·네이버 이미지 검색, 공유마당): 확장은 검색어를 어디에도 보내지 않습니다. [구글 이미지에서 찾기]·[네이버 이미지에서 찾기]·[공유마당에서 찾기]를 누르면 그 검색 화면이 새 탭으로 열리고, 그 뒤는 사용자가 그 사이트를 직접 쓰는 것과 같습니다(각 사이트의 개인정보 처리방침이 적용됩니다). 그림에 적은 출처 줄은 초안 기록과 함께 이 기기에만 저장합니다.
  • 사이트 구조 설정 확인
    • 사이트 화면이 바뀌어도 확장을 새로 설치하지 않고 고칠 수 있도록, 패널을 열 때 6시간에 한 번(확인하지 못했으면 1시간 뒤) 사이트 구조 설정 파일(JSON)을 01-june-0.github.io(GitHub Pages)에서 받습니다.
    • 요청에는 쿠키, 리퍼러, 사용자 식별자를 담지 않습니다. GitHub는 일반 웹 요청처럼 IP 주소 같은 접속 정보를 볼 수 있으며, 여기에는 GitHub의 개인정보 처리방침이 적용됩니다.
    • 받은 파일은 개발자 서명을 확인한 뒤에만 쓰고, 실행되는 코드는 받지 않습니다.

다루지 않는 것

  • 비밀번호나 로그인 정보는 읽거나 입력하지 않습니다. 이미 로그인된 상태만 이용합니다.
  • 방문 기록이나 다른 탭의 내용은 읽지 않습니다. 사용자가 연결한 탭과 작업용으로 연 창만 다룹니다.

지우기

  • 설정 → 데이터 → 전체 초기화로 모든 데이터를 지웁니다.
  • 기록에서 초안을 하나씩 지울 수 있습니다.
  • 확장 프로그램을 삭제하면 브라우저에 저장된 데이터도 모두 지워집니다.

바뀌면

이 문서를 고치면 위의 날짜를 바꿉니다. 데이터를 다루는 방식이 바뀌면 확장 안에서 다시 동의를 받습니다.

English

Sulsul Post has no developer server that receives your data, and does not collect, sell or share your data. It uses no analytics, ads or trackers.

Stored only on your device

The following stays in this browser profile (chrome.storage, IndexedDB):

  • Settings, your post details (topic, keywords, notes, …) and your consent record
  • Drafts and their versions (the latest 30), and the images and photos you generated or attached
  • The tab you connected as the write screen (its address and title)
  • Posts read for "reference top posts"
    • The text excerpts are deleted automatically after 24 hours.
    • The titles and addresses of the posts used, with summary statistics (length, frequent heading words and tags), stay with that draft's record.
  • An activity log (the latest 500 entries), with long text, search terms in addresses, e-mail addresses and phone numbers masked
  • The site-structure files it downloaded and when it last checked (see "Site-structure check" below)

Sent out only when you run a step

Sulsul Post acts only when you press a button, only on sites you chose, in ordinary browser windows.

  • AI services (Gemini, ChatGPT, Claude)
    • It opens the AI site you are already signed in to in a pop-up window and types the prompt for you.
    • The prompt contains your post details, reference excerpts and the draft. If you choose, it also contains the photos and reference images you attached.
    • That content is handled under the AI service's own privacy policy. A setting sends it as a temporary chat (ChatGPT) or an incognito chat (Claude).
  • Naver Search and Naver Blog: "reference top posts" reads search results and blog posts in a browser window.
  • Write screens (Naver Blog, Naver Cafe, Tistory)
    • It fills the screen you connected with the title, body, images and tags.
    • Images are uploaded by that site's own editor to its own servers. You always publish yourself.
  • Instagram and Threads: when you press "put into Instagram / Threads", it fills the composer of the tab you have open with the pictures and caption, or the series of posts. You share or post yourself.
  • AI image addresses: to fetch an image you generated, it opens the AI service's image address.
  • Image search (Google and Naver image search, Gongu Madang): the extension sends your search words nowhere. Pressing "search Google Images", "search Naver Images" or "search Gongu Madang" (the Korea Copyright Commission's free-use works) opens that search in a new tab; from there it is the same as using that site yourself (its own privacy policy applies). A credit line you write for a picture is stored only on this device, with the draft.
  • Site-structure check
    • So that a change on a site can be fixed without reinstalling the extension, it downloads site-structure files (JSON) from 01-june-0.github.io (GitHub Pages) when the panel opens, at most once every 6 hours (1 hour after a failed check).
    • The requests carry no cookies, referrer or user identifier. GitHub can see connection details such as your IP address, as with any web request; GitHub's privacy statement applies to that.
    • A downloaded file is used only after the developer's signature checks out, and no code is ever downloaded.

Not handled

  • It never reads or types passwords or sign-in details. It only uses sessions you are already signed in to.
  • It does not read your browsing history or other tabs — only the tab you connected and the windows it opens for a task.

Deleting your data

  • Settings → Data → Reset everything deletes all data.
  • Drafts can be deleted one by one in History.
  • Removing the extension deletes everything it stored in your browser.

Changes

When this policy changes, the date above changes. If the way data is handled changes, the extension asks for your consent again.
